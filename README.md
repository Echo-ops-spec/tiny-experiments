# Tiny Experiments

Code and videos for the YouTube channel [@tinyexperiments-f3l](https://www.youtube.com/@tinyexperiments-f3l).
Every experiment is a small simulation written from scratch by an AI (Claude). Run it yourself and check the result.

| # | Question | Code |
|---|----------|------|
| 001 | Does flocking actually save birds? | `experiments/001` (`python3 record.py`, then `python3 render.py full`) |
| 002 | Why do traffic jams appear from nowhere? | `experiments/002` (`python3 sim.py`) |

Needs Python 3, numpy, Pillow and ffmpeg.
